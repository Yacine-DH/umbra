General

How Umbra looks, starts and runs.

Install the Umbra GNOME extension for the best experience
Widgets now sit on the desktop through XWayland. The extension pins them natively: above the desktop icons, out of the overview and Alt+Tab.
Zoom
Size of this window's text and controls. Also Ctrl + mouse wheel, Ctrl + plus or minus, and Ctrl + 0.
Start with Windows
Your widgets appear on the desktop when you sign in.
Keep Umbra up to date
Once a day Umbra asks GitHub for a newer version and downloads it in the background. It only installs when you click Update now.
Hide during fullscreen apps
Widgets step aside while a fullscreen game or video is in the foreground.
Refresh interval
How often widgets fetch fresh data. They pause while the PC is locked or the display is off.

Layouts

Save where your widgets are and which ones are on, then switch between setups. A layout is pinned to the monitors it was saved on.

Switch layouts automatically when monitors change
When you dock or undock, Umbra waits a moment and applies the layout pinned to the new monitor setup. Layouts that aren't pinned to it are left alone.
Save current layout
Saving under an existing name replaces it. The layout is pinned to the monitors you have connected now.
Community

Widgets made by people like you

Every widget runs in a sandbox and can only reach the sites it declares. Built one? Open a pull request and it shows up here for everyone.

Appearance

Pick a theme for all your widgets, then fine-tune it if you like.

Customize colors, text and size
Themes are plain data with no code, so they can't run anything or load files from the internet. Made one? Add themes/<id>/theme.json in a pull request and it shows up here for everyone.

Hotkeys

System-wide shortcuts that work while any app has focus. Click a shortcut, then press the keys (at least one of Ctrl, Alt or Win). Esc cancels, Backspace turns it off.

Data & privacy

What each widget can reach, run and has saved. Widgets can only contact the hosts listed here; anything else is blocked.

Count my widget installs
When you install a widget from the catalog, Umbra sends one anonymous +1 for that widget, so Browse can show how many people use it. Nothing else: no id, no version, nothing about you or this PC, and updates aren't counted. Off also stops Browse from loading the counts.

Add a widget

From the catalog

  1. Open Browse and find one: search, or pick a category.
  2. Press Install. It shows up on your desktop right away, behind your windows.
  3. To move or resize it, turn on Arrange (in My widgets, the tray menu or its hotkey), drag it where you want, then press Done.
  4. Its options (city, size, colors...) are in My widgets. Want two? Use Add another copy.

Your own, or one a friend sent

  1. A widget is a folder with a widget.json and an index.html. Start one with umbractl new <id>.
  2. To share it, zip the folder. A .umbrawidget file is the same zip, renamed; double-click one to install it.
  3. Or use Install from… on Browse: File, Folder or URL. Umbra checks every file first and asks before it gets access to websites, system info, media, notifications or commands.
